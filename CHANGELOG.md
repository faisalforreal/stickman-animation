# Changelog

## 0.2.0
- HD by default: 1280x720 GIF (supersampled 4x), `gif` / `gif-hd` / `video-hd` / `video-4k` format flags.
- `bg-black` / `bg-white` (with `fg-white` / `fg-black`) colour themes.
- `export()`, `sheet()` and `main()` helpers; MP4 output streamed through ffmpeg (flat memory at 4K).
- Multi-process rendering (`workers=`), cross-platform font lookup, `stickman` command line.
- Packaged as a pip project and as a Claude skill from one source.

## 0.1.0
- First version: robot and human stickmen, packets, windows, nodes, typewriter text, Bangla text, GIF output.
